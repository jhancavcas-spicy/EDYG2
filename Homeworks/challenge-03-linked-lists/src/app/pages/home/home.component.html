Estructuras de datos enlazadas, en Angular

Este proyecto demuestra de forma visual e interactiva cómo funcionan una lista enlazada simple y una lista doblemente enlazada. Ambas están implementadas desde cero con nodos y referencias (next y prev), sin usar un array como estructura interna.

Singly Linked List

Lista Enlazada

Un reproductor de canciones que recorre una LinkedList nodo por nodo, usando la referencia next para avanzar.

Ver demostración
Doubly Linked List

Lista Doblemente Enlazada

Un historial de navegación que usa una DoublyLinkedList para moverse hacia atrás y hacia adelante con prev y next.
